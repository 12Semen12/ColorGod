# 🎨 Color God v30.0

Продвинутый инструмент для генерации, анализа и экспорта цветовых палитр. Создан для дизайнеров, фронтенд-разработчиков и тех, кто устал тыкать в color picker вручную.

## ✨ Фичи
- **Генерация палитр**: Случайные цвета или на основе гармоний (комплементарная, триадная, аналоговая).
- **Конвертация форматов**: HEX, RGB, HSL, CMYK — всё из коробки.
- **Экспорт**: Сохраняй палитры в JSON, CSS-переменные, SCSS-мапы или градиенты.
- **Визуализация**: Превью палитры с автоматическим подбором контрастного текста.
- **История**: Последние 10 палитр сохраняются локально.
- **Горячие клавиши**: Навигация стрелками, копирование по Enter, генерация по `Ctrl+G`.

## 🚀 Установка
```bash
pip install Pillow
python "rondom color 30.0.py"
```


## 🛠 Технологии
- Python 3.x
- Tkinter (GUI)
- Pillow (опционально, для экспорта в PNG)
