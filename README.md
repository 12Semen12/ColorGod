# ColorGod
Color God v30.0—генератор палитр на Python/Tkinter. Создаёт цвета по гармониям (триада, комплементарная), конвертирует в HEX/RGB/HSL/CMYK. Экспорт в CSS-переменные, SCSS, JSON и PNG (через Pillow). Тёмная тема, история из 10 записей, горячие клавиши и live-preview HEX-кодов с автоконтрастом. Идеально для фронтендеров, которым лень тыкать в пипетку.
запуск
открой папку dist там открой ColorGod.exe
